## Import requirements
- Keep the downloaded asset page and licence evidence.
- Prefer glTF/GLB for Godot.
- Check skeleton compatibility before connecting animation clips.
- Reduce texture sizes and mesh complexity for Android.
- Keep source assets separate from generated project files.
