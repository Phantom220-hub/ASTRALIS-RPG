# ASTRALIS: Echoes of the Lost World

An original mobile-first 3D anime-inspired action RPG prototype built with Godot 4.

## Target
- Engine: Godot 4.x
- Platform: Android
- Rendering: Mobile-friendly Forward+ alternative / Compatibility-friendly scene design
- Camera: third-person
- Initial target device: mid-range Android hardware

## Art direction
A bright fantasy world with layered landscapes, atmospheric distance, stylized materials, readable silhouettes, soft light, glowing runes, particles and expressive character motion. The goal is an original visual identity, not a copy of another game.

## First milestone
The first milestone establishes the playable foundation: project settings, third-person player, camera, touch-friendly controls, a first exploration area, basic NPC/enemy placeholders, UI, and animation hooks. Content will be expanded in later milestones.

## Asset policy
Only assets whose individual licences permit the intended use will be included. Prefer CC0 assets where practical. Every imported asset must be recorded in [ASSET_CREDITS.md](ASSET_CREDITS.md), including source, creator, licence, and the original asset page. Never assume that every download on a marketplace has the same licence.

Potential sources for environment materials, character kits, animation, UI and audio are listed in the asset register. External assets will be downloaded and committed only after their file formats, licence terms, and mobile suitability are checked.

## Import
1. Download this repository as a ZIP or clone it.
2. Open the project folder in Godot 4.
3. Let Godot import the project.
4. Open the main scene and run on desktop or Android.

The current repository is an early development foundation, not a finished game. Real-device testing is required for performance and touch controls.
